1. Ouvrir mon espace de gestion

Le classeur est public en lecture, mais seul le titulaire d'une autorisation GitHub peut le modifier. Pour la première utilisation, crée un jeton d'accès GitHub à permissions limitées : propriétaire jkarmati, dépôt classeur-6eme uniquement, autorisation Contents : Read and write. Fixe-lui une durée d'expiration. Il faudra en créer un nouveau à son expiration.

Sécurité : ce jeton est un véritable droit d'écriture sur ton dépôt. Garde-le secret, ne le transmets pas aux élèves et utilise cette page sur ton propre appareil. Il n'est ni inscrit dans le site, ni enregistré dans le navigateur : il reste seulement en mémoire pendant cette visite.
