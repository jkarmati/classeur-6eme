# Classeur virtuel de 5e

Site des élèves : https://jkarmati.github.io/classeur-6eme/5eme/

Espace enseignant : https://jkarmati.github.io/classeur-6eme/5eme/gestion.html

Le même design et le même fonctionnement que le classeur de 6e : fiches avant les 6 intercalaires, feuilles à tourner, affichage des faces extérieures des PDF, impression, suivi « Bien rangé ».

Pour déposer un document, ouvre l'espace enseignant avec le même jeton GitHub. Choisis l'intercalaire, ajoute le PDF ou l'image, puis ordonne les fichiers si nécessaire. GitHub Pages mettra le site à jour après publication.

Les documents sont rangés uniquement dans les dossiers de cette classe : `5eme/documents/`. La mise à jour n'affecte pas les deux autres classeurs.

L'accès avec phrase de passe enregistré sur ce navigateur peut être partagé entre les trois pages de gestion, car elles utilisent le même dépôt GitHub et le même site.
