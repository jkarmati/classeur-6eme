1. Ouvrir mon espace de gestion

Le classeur est public en lecture, mais seul le titulaire d'une autorisation GitHub peut le modifier. Les classeurs 6e, 5e et 3e sont hébergés dans le même dépôt ; ton jeton GitHub actuel fonctionne donc pour les trois, ainsi que ta phrase de passe si tu l'as enregistrée sur cet appareil. Pour la première utilisation, crée un jeton d'accès GitHub à permissions limitées : propriétaire jkarmati, dépôt classeur-6eme uniquement, autorisation Contents : Read and write. Fixe-lui une durée d'expiration. Il faudra en créer un nouveau à son expiration.

Sécurité : le jeton donne le droit de modifier ton dépôt GitHub. Pour éviter de le retaper, tu peux l'enregistrer chiffré uniquement dans ce navigateur, protégé par une longue phrase de passe. N'utilise cette option que sur ton appareil personnel. Rien n'est enregistré en clair ni publié sur GitHub.

🔒 Déverrouiller mon classeur

Le jeton GitHub est enregistré sous forme chiffrée dans ce navigateur. Saisis ta phrase de passe personnelle.
